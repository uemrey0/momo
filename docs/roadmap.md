# Roadmap

## Done in 0.1.0

- **A living character:** procedural engine with twelve moods, idle behaviours, cursor
  attention, poke physics, sleep and wake, reactions and particles; seven looks plus custom
  JSON character packs.
- **Local brain and chat panel:** Apple Intelligence, Ollama and LM Studio; a Spotlight-style
  panel with Chat, Today (tasks and habits) and Notes; tasks, reminders, notes, habits and
  memory as tools.
- **Bring your own subscription:** Codex CLI (ChatGPT plan) and Gemini CLI bridges; Claude,
  OpenAI, Gemini and OpenRouter API keys; the brain router with consent and personal data
  masking; an outbound log.
- **Voice:** on-device dictation, spoken replies with lip sync, an optional "Hey Momo" wake
  word.
- **Context and connections:** calendar, meeting nudges, reminder notifications, music,
  battery and late-night reactions, a morning greeting, focus sessions; the `momo-mcp` server
  and an MCP client for the user's own servers.
- **Superpowers:** opening apps and links, running Shortcuts, reading the clipboard and the
  screen, all with confirmation where it matters.
- **Shipping:** English and Turkish, onboarding, settings, launch at login, update checks,
  DMG packaging and a release workflow.
